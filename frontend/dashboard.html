Top Error Codes

Runbook - Tier 1 Quick Reference

SAML_ASSERTION_INVALID

Check SP/IdP metadata sync. Re-upload SP metadata in IdP console. Verify clock skew less than 5 min.

TOKEN_EXPIRED / OIDC_MISMATCH

Force token refresh via app settings. Confirm redirect URI matches exactly in IdP config.

ACCOUNT_LOCKED

Unlock in IdP admin panel. Check for brute-force pattern - escalate to Tier 2 if more than 5 attempts.

FEDERATION_ERROR

Verify trust relationship between IdP and SP. Check certificate expiry. Escalate if unresolved.

MFA_TIMEOUT

User did not complete MFA in time. Ask them to retry. If repeated, check authenticator app sync.
